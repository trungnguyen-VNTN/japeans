# Japeans

Japanese-learning web app for Vietnamese learners: dictionary, kanji/radical analysis (AI-assisted), study sets (flashcard-set style) and SRS. Product plan: `docs/PLAN.md`. UI language: Vietnamese.

## Stack
- Next.js 16 (App Router, `src/`), React 19, TypeScript, Tailwind CSS 4
- PostgreSQL 17 via Prisma 7 (driver adapter `@prisma/adapter-pg`). Client is generated to `src/generated/prisma` (git-ignored); import the shared client from `@/lib/db`.
- Meilisearch (dictionary search) and Redis (cache, AI rate limit), all in `docker-compose.yml`.
- AI: Anthropic API (`ANTHROPIC_API_KEY`), added when Module C/B starts.

## Commands
- `npm run services:up` / `services:down`: start/stop Postgres, Meilisearch, Redis (Docker Desktop must be running)
- `npm run dev`: dev server on http://localhost:3000
- `npm run db:migrate -- --name <name>`: create and apply a migration after editing `prisma/schema.prisma`
- `npm run db:generate` / `db:studio`
- `npm run lint`, `npm run typecheck`, `npm run build`

## Conventions
- Prisma config file is `prisma7.config.ts` (generated by Prisma 7.10); always pass `--config prisma7.config.ts` (the npm scripts do). Stay on Prisma 7 — `prisma@latest` resolves to an 8.x RC with a different CLI.
- Dictionary data (Word, Kanji, Radical, KanjiComponent, Example) comes from import scripts in `scripts/import/`; raw downloads go in `data/raw/` (git-ignored). Never hand-edit or AI-generate radical decompositions.
- AI output is cached in `AIContent` (unique per type + targetKey) and only shown as approved or labelled "AI".
- Study sets (Module H) and SRS (Module D) share one card model: `SetCard` + `CardProgress` (FSRS state) + `ReviewLog`.
- Credentials in `.env` / `docker-compose.yml` are dev-only.
